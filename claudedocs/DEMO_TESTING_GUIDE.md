## 🐛 Troubleshooting (문제 발생 시)

### 문제 1: 추천 차량이 안 나옴
**증상**: `[DemoPool] 1차 필터링 완료: X대 → 0대`

**해결**:
1. Railway 로그에서 필터링 로그 확인
2. 가장 많이 걸린 필터 확인 (🚫 메시지)
3. `DEMO_FILTERS` 완화 (예: 주행거리 20만km로 변경)

```typescript
// server/lib/demo/DemoVehiclePool.ts
distance: {
  max: 200000  // 10만 → 20만km
}
```

### 문제 2: 더미 가격 차량 여전히 나옴
**증상**: 999만원, 7777만원 차량 추천

**해결**:
1. `isDummyPrice()` 함수에 패턴 추가
2. DB 데이터 점검

```typescript
const dummyPrices = [999, 7777, 9999, 1111, 2222, 3333, 4444, 5555, 6666, 8888, 10000];
```

### 문제 3: 차종 불일치 (SUV → 세단)
**증상**: SUV 요청했는데 세단 추천

**해결**:
1. `matchesCarType()` 함수 로그 확인
2. 모델명 직접 매칭 추가

```typescript
popularSUVs: [
  '싼타페', '쏘렌토', '팰리세이드', '카니발',
  '추가모델명'  // 여기 추가
]
```

### 문제 4: 링크 클릭 시 404
**증상**: detailUrl 존재하지만 페이지 없음

**해결**:
1. `hasValidDetailUrl()` 강화
2. URL 형식 검증 추가

```typescript
// 추가 검증
if (!url.startsWith('http') && !url.startsWith('/')) {
  return false;
}
```

3. **브랜드 제한**: "BMW만" (신뢰 브랜드 아님)
