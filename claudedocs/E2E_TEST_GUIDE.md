## 📋 시나리오 A: 가족용 SUV 추천

### 1단계: 랜딩 페이지 접속
1. https://carfinaifinal-production-15a8.up.railway.app 접속
2. "🎬 시나리오 A (가족용 SUV)" 버튼 클릭

### 2단계: 프로필 자동 완성 확인
자동으로 입력된 프로필 확인:
```yaml
이름: 김민준
연령: 30대
지역: 서울
용도: [출퇴근, 가족용, 주말 나들이]
예산: 2500-3500만원
선호 브랜드: [현대, 기아]
차량 타입: SUV
연료 타입: 디젤
변속기: 오토
중요도:
  - 가격: 8/10
  - 연비: 7/10
  - 안전성: 9/10 ⭐ (최우선)
  - 디자인: 6/10
  - 브랜드: 5/10
TCO 프로필:
  - 연간 주행거리: 15,000km
  - 보유 기간: 5년
  - 월 소득: 500만원
  - 기타 대출: 없음
```

### 3단계: AI 상담 시작
1. "AI 상담 시작" 버튼 클릭
2. 채팅방 진입 확인

### 4단계: 시나리오 A 메시지 입력
```
3000만원대 가족용 SUV 찾아요. 안전하고 실용적인 걸로요.
```

### 5단계: 추천 진행 확인
다음 메시지들이 순서대로 표시되어야 함:
- ✅ "🔍 조건에 맞는 차량 XXX대를 찾았어요"
- ✅ "✅ 베스트 3 차량을 선정했어요"
- ✅ "✅ 각 차량별 최적의 구매 방법을 찾았어요"

### 6단계: 추천 결과 확인
**기대 결과**: 3대의 차량 카드 표시

**1위 차량 (예상)**:
- 제조사: 현대 또는 기아
- 차종: SUV (투싼, 스포티지, 싼타페 등)
- 가격: 2500-3500만원 범위
- TOPSIS 점수: 0.75 이상
- 매칭도: 85% 이상

**확인사항**:
- [ ] 3대의 차량 카드가 모두 표시됨
- [ ] 각 카드에 TOPSIS 점수 표시
- [ ] 각 카드에 매칭도 표시
- [ ] 차량 이미지가 표시됨
- [ ] "TCO 분석 보기" 버튼 표시

### 7단계: TCO 분석 확인
1. 1위 차량 카드에서 "TCO 분석 보기" 클릭
2. TCO Comparison Chart 표시 확인:
   - [ ] 3대 차량 비교 스택 바 차트
   - [ ] 5개 비용 항목 (취득세, 자동차세, 정비비, 감가상각, 연료비)
   - [ ] 법적 근거 표시 (지방세법 제11조, DOE/ANL 88원/km)

3. "TCO 상세 분석" 클릭
4. TCO Detail Modal 확인:
   - [ ] 연도별 비용 타임라인 (5년)
   - [ ] 누적 비용 그래프
   - [ ] 비용 절감 인사이트

### 8단계: 추천 이유 확인
1. "추천 이유 보기" 버튼 클릭
2. Recommendation Reason Modal 확인:
   - [ ] TOPSIS 6기준 평가 점수
   - [ ] 안전성이 높은 점수 (9/10 이상)
   - [ ] TCO 우수성 설명
   - [ ] MACRec 협업 결과

## ⚠️ 예상 오류 및 해결

### 오류 1: 프로필이 자동으로 입력되지 않음
**원인**: URL 파라미터가 제대로 전달되지 않음
**해결**:
1. URL에 `?demo=A` 또는 `?demo=B`가 포함되어 있는지 확인
2. 브라우저 캐시 삭제 후 재시도

### 오류 2: 추천 결과가 표시되지 않음
**원인**: WebSocket 연결 실패 또는 백엔드 오류
**해결**:
1. 브라우저 개발자 도구 콘솔 확인
2. Network 탭에서 WebSocket 연결 확인 (ws://...)
3. 백엔드 Health Check API 확인

### 오류 3: 추천된 차량이 조건에 맞지 않음
**원인**: 데이터베이스에 해당 조건의 차량이 부족
**해결**:
1. 예산 범위를 넓게 조정
2. 차량 타입 조건 완화
3. 필터링 로직 확인 (SearcherAgent.ts)

### 오류 4: TCO 분석에서 법적 근거가 표시되지 않음
**원인**: 프론트엔드 컴포넌트 렌더링 문제
**해결**:
1. TCOComparisonChart.tsx 컴포넌트 확인
2. 브라우저 콘솔에서 에러 메시지 확인
