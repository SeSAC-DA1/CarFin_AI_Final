  - [ ] 지역 입력 필드
- [ ] Step 2: 차량 용도 선택
  - [ ] 체크박스 (출퇴근, 가족용, 레저, 업무용 등)

  - [ ] 실시간 숫자 업데이트
  - [ ] 단위 표시 (만원)
- [ ] Step 4: 중요도 가중치 조정
  - [ ] 6개 슬라이더 (가격, 연비, 안전성, 디자인, 브랜드, 성능)
  - [ ] 1-10 범위
  - [ ] 실시간 업데이트
- [ ] 진행 바 표시

## ✅ Phase 4: TCO 금융 분석 테스트 🌟

### 4.1 TCO Comparison Chart (3대 비교)
- [ ] "TCO 비교 보기" 버튼 클릭
- [ ] 3대 차량 비교 스택 바 차트 표시
- [ ] 5개 비용 항목 구분:
  - [ ] 취득세 (7%)
  - [ ] 자동차세
  - [ ] 정비비
  - [ ] 감가상각
  - [ ] 연료비
- [ ] 색상으로 항목 구분
- [ ] 총 TCO 금액 표시 (상단 또는 레이블)
- [ ] 법적 근거 명시:
  ```
  📜 법적 근거
  • 취득세: 지방세법 제11조 (7%)
  • 자동차세: 지방세법 제127조
  • 정비비: DOE/ANL 88원/km
  • 감가상각: 정률법 20%
  • 연료비: 실시간 유가 × 연비
  ```

### 4.2 TCO Detail Modal (개별 차량 상세)
- [ ] 차량 카드에서 "TCO 상세 분석" 버튼 클릭
- [ ] 모달 열림
- [ ] **연도별 타임라인** 표시 (5년):
  - [ ] 1년차 비용
  - [ ] 2년차 비용
  - [ ] 3년차 비용
  - [ ] 4년차 비용
  - [ ] 5년차 비용
- [ ] **누적 비용 그래프** (선 그래프)
- [ ] **비용 절감 인사이트**:
  - [ ] "2위 차량 대비 X만원 절약"
  - [ ] 연료 타입별 절감액
  - [ ] 최적 보유 기간 추천
- [ ] **5개 비용 항목 상세**:
  - [ ] 각 항목별 계산식 설명
  - [ ] 법적 근거 링크 또는 툴팁
- [ ] 개인화 변수 표시:
  - [ ] 연간 주행거리 (annualKm)
  - [ ] 보유 예정 기간 (ownershipYears)

### 4.3 TCO 계산 정확성 검증
**1위 차량 (예: 현대 투싼 2980만원) 기준:**

- [ ] **취득세** 계산:
  - 공식: 차량 가격 × 7%
  - 예상: 2980만원 × 0.07 = 208.6만원
  - 실제: ______만원 (차트 확인)
  - ✅ / ❌

- [ ] **자동차세** 계산 (5년 누적):
  - 공식: 배기량 기준 + 연식 감가
  - 예상: 약 80-100만원 (2000cc 기준)
  - 실제: ______만원
  - ✅ / ❌

- [ ] **정비비** 계산:
  - 공식: 88원/km × 연간 주행거리 × 5년
  - 예상: 88 × 15,000km × 5년 = 660만원
  - 실제: ______만원
  - ✅ / ❌

- [ ] **감가상각** 계산:
  - 공식: 차량 가격 × 정률법 20%
  - 예상: 2980만원 × 0.20 = 596만원
  - 실제: ______만원
  - ✅ / ❌

- [ ] **연료비** 계산 (5년):
  - 공식: (연간 주행거리 / 연비) × 유가 × 5년
  - 예상: (15,000 / 14.5) × 1,800원 × 5년 = 약 930만원
  - 실제: ______만원
  - ✅ / ❌

- [ ] **총 TCO** 합계:
  - 예상: 208.6 + 90 + 660 + 596 + 930 = 2,484만원
  - 실제: ______만원
  - ✅ / ❌
