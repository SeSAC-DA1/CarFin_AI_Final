   - AI: [자동 추출] usage → 프로필 업데이트

### ✅ **포트폴리오 가치**

#### **1. Full-Stack 개발 역량**
- React + TypeScript + Node.js + PostgreSQL 전체 구현
- WebSocket 실시간 양방향 통신
- RESTful API + WebSocket 하이브리드 아키텍처
- shadcn/ui 디자인 시스템 활용

#### **2. AI/ML 통합 능력**
- Google Gemini 2.5 Flash API 통합
- 자연어 처리 (NLP) - 사용자 메시지에서 구조화된 데이터 추출
- 프롬프트 엔지니어링 - AI 질문 생성, 컨텍스트 이해

#### **3. 복잡한 비즈니스 로직 구현**
- **MACRec 멀티에이전트 시스템** (SIGIR 2024)
  - Manager Agent, User Analyst, Searcher Agent 협업
  - 에이전트 간 통신 프로토콜 설계
- **AHP-TOPSIS 다기준 의사결정** (수학 알고리즘)
  - 6가지 평가 기준 (가격, 연비, 안전성, 브랜드, 상태, 옵션)
  - 가중치 기반 정규화 및 점수 계산
- **Alibaba 개인화 재정렬** (RecSys 2019)
  - 사용자 프로필 기반 개인화 점수
  - Top-N 재정렬 알고리즘

#### **4. 시스템 설계 능력**
- **상태 관리**: localStorage + WebSocket 동기화
- **에러 핸들링**: ErrorBoundary + 재연결 로직
- **성능 최적화**: Redis 캐싱 (Railway)
- **배포 경험**: Railway (백엔드) + Vercel (프론트엔드)
