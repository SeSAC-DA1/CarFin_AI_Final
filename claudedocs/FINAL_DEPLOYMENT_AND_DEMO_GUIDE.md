## ⚠️ 중요: PostgreSQL 인덱스 생성 필요

### 현재 상태
- ❌ **인덱스 미생성** → DB 쿼리 800ms (느림)
- ✅ 인덱스 생성 후 → DB 쿼리 80ms (-90%)

### 즉시 실행 필요 (5분 소요)

#### 방법 1: Railway Dashboard (추천)
```bash
# 1. Railway Dashboard 접속
https://railway.app/dashboard

# 2. 프로젝트 선택: carfinaifinal-production-15a8
# 3. Database 탭 클릭
# 4. Query Console 열기
# 5. scripts/create_indexes.sql 전체 복사 & 실행
# 6. 6개 인덱스 생성 확인
```

#### 방법 2: psql (로컬에서)
```bash
psql "postgresql://carfin_admin:carfin_secure_password_2025@carfin-db.cbkayiqs4div.ap-northeast-2.rds.amazonaws.com:5432/carfin"

\i scripts/create_indexes.sql
```

#### 생성할 인덱스 (6개)
1. `idx_vehicles_search_composite` (car_type, price, manufacturer)
2. `idx_vehicles_price_range` (price WHERE BETWEEN 1000-5000)
3. `idx_vehicles_car_type`
4. `idx_vehicles_manufacturer`
5. `idx_vehicles_model_year`
6. `idx_vehicles_fuel_type`

#### 검증 방법
```sql
-- 인덱스 확인
SELECT indexname FROM pg_indexes WHERE tablename = 'vehicles' AND indexname LIKE 'idx_vehicles_%';

-- 6개 인덱스가 모두 표시되어야 함
```
