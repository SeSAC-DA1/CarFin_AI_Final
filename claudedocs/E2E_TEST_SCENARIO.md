- [ ] 차량 이미지

## 🚨 예상 이슈 및 대응

### Issue 1: 예산 초과 차량 추천
**증상**: 3000만원 이하 요청했는데 3500만원, 4000만원 차량 추천
**원인**: userMessage 예산 우선순위 미적용
**현재 상태**: ✅ 수정 완료 (commit 764a785)
**검증 방법**: 모든 추천 차량 가격 확인

### Issue 2: 차종 오분류
**증상**: SUV 요청했는데 스포츠왜건(Volvo V60 등) 추천
**원인**: 차종 필터링 로직 오류
**현재 상태**: ✅ 수정 완료 (commit 380317c)
**검증 방법**: 차종 필드 확인

### Issue 3: 금융 옵션 미표시
**증상**: 일시불만 표시, 할부/리스 없음
**원인**: userProfile 기본값 누락으로 division by zero
**현재 상태**: ✅ 수정 완료 (commit cbacb6f - safeUserProfile)
**검증 방법**: 금융 옵션 모달에서 3가지 옵션 확인

### Issue 4: 피드백 메시지 중복
**증상**: "이전 추천에 대한 피드백: 이전 추천에 대한 피드백: ..."
**원인**: FeedbackSection과 ChatInterface 양쪽에서 접두사 추가
**현재 상태**: ✅ 수정 완료 (commit 3e2c51d)
**검증 방법**: 재추천 요청 시 메시지 확인

### Issue 5: Agent 이름 불일치
**증상**: "매니저 에이전트", "검색 에이전트", "금융 자문가" 혼용
**원인**: MessageBubble.tsx 매핑 불일치
**현재 상태**: ✅ 수정 완료 (commit 3e2c51d - 2-4글자 통일)
**검증 방법**: AgentStatusPanel 메시지 확인

### Issue 6: AI 응답 톤 너무 딱딱함
**증상**: "최종 추천 차량을 제시합니다" 등 형식적 표현
**원인**: Gemini 프롬프트 형식적 톤
**현재 상태**: ✅ 수정 완료 (commit 591f9b3 - 친절한 톤으로 전면 수정)
**검증 방법**: AI 응답 메시지 톤 확인
