### Commit 764a785: CRITICAL FIX (2025-10-13)
**문제**: ManagerAgent가 userMessage를 SearcherAgent에 전달하지 않음
**증상**: "3000만원 이하" 요청했는데 3590만원, 4300만원 차량 추천
**원인**: `task.input = { criteria: extractedProfile }` (userMessage 누락)
**수정**: `task.input = { criteria: extractedProfile, userMessage }` 추가
**중요도**: 🔴 P0 - 데모 블로커 (예산 필터링 핵심 기능)

**수정**: `/(\d{1,4})만원/` → "만원" 키워드 필수
**중요도**: 🔴 P0 - 데모 블로커 (추천 자체가 안나옴)
