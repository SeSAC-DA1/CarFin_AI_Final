# TCO 차트 개선 방안 - 3가지 제안

## 🎯 현재 문제점

### ❌ Area Chart (현재)
```
[큰 영역 차트 400px]
- 누적 비용 추이
- 색상 영역만 넓음
- "이게 뭐지?" 반응
```

**문제:**
1. 정보 전달력 약함
2. 큰 공간 차지
3. 사용자 와닿지 않음

---

## 💡 제안 1: **Radar Chart (거미줄 차트)** ⭐ 추천

### 장점:
- ✅ **5개 항목 한눈에 비교** (취득세, 자동차세, 정비비, 감가상각, 연료비)
- ✅ **차량 3대 겹쳐서 표시** → 어떤 차량이 어떤 항목에서 강한지 직관적
- ✅ **"강점/약점" 명확** → "1위는 연료비가 저렴하네!"
- ✅ **작은 공간** (300px) → 핵심만 표시

### 시각적 효과:
```
        취득세
          /\
         /  \
자동차세 -------- 정비비
        \  /
         \/
      감가상각    연료비

[3개 차량 겹친 선 → 차이 명확]
```

### 사용자 반응:
> "오! 1위는 연료비가 저렴하고, 2위는 정비비가 저렴하네!"

---

## 💡 제안 2: **Horizontal Stacked Bar (가로 누적 막대)**

### 장점:
- ✅ **비용 구성 비교** → 5개 항목이 어떻게 쌓이는지
- ✅ **총합 직관적** → 막대 길이 = 총 TCO
- ✅ **차이 명확** → "1위가 2위보다 300만원 저렴"
- ✅ **작은 공간** (200px)

### 시각적 효과:
```
1위 ▓▓░░▓▓▓▓▓░░░  2,500만원
2위 ▓▓░░░▓▓▓▓▓░░  2,700만원
3위 ▓▓▓░░▓▓▓▓▓░░  2,800만원

[색상: 취득세/자동차세/정비비/감가상각/연료비]
```

### 사용자 반응:
> "1위가 확실히 짧네! 200만원 차이구나"

---

## 💡 제안 3: **Split View (분할 뷰)** - 하이브리드

### 구성:
```
[왼쪽 50%]              [오른쪽 50%]
Radar Chart             Top 3 요약 카드
(5개 항목 비교)          (총 TCO + 항목별)
```

### 장점:
- ✅ **Radar로 차이 비교**
- ✅ **요약 카드로 정확한 숫자**
- ✅ **Area Chart 제거** → 공간 확보

---

## 🏆 최종 추천: **Radar Chart + 요약 카드**

### 이유:
1. **직관성 최고** (거미줄 = 강약점 한눈에)
2. **작은 공간** (현재 50% 공간만 사용)
3. **임팩트** ("오!" 반응 유도)
4. **차별화** (다른 추천 시스템에 없음)

### 레이아웃:
```
┌─────────────────────────────────────┐
│  TCO 비교 분석                       │
├─────────────────────────────────────┤
│                                     │
│  [Radar Chart - 5개 항목 비교]        │
│  (300px 높이)                        │
│                                     │
├─────────────────────────────────────┤
│  [Top 3 요약 카드]                   │
│  1위 | 2위 | 3위                     │
│  (각 카드에 총 TCO + 5개 항목 막대)    │
└─────────────────────────────────────┘

[Area Chart 제거 → 400px 공간 절약]
```

## 📊 구현 상세: Radar Chart

### Recharts 사용:
```tsx
<RadarChart>
  <PolarGrid />
  <PolarAngleAxis dataKey="항목" />
  <PolarRadiusAxis angle={90} domain={[0, 'auto']} />
  <Radar
    name="1위"
    dataKey="value1"
    stroke="#F59E0B"
    fill="#F59E0B"
    fillOpacity={0.3}
  />
  <Radar
    name="2위"
    dataKey="value2"
    stroke="#3B82F6"
    fill="#3B82F6"
    fillOpacity={0.3}
  />
  <Radar
    name="3위"
    dataKey="value3"
    stroke="#EF4444"
    fill="#EF4444"
    fillOpacity={0.3}
  />
</RadarChart>
```

### 데이터 구조:
```typescript
const radarData = [
  { 항목: '취득세', '1위': 210, '2위': 210, '3위': 210 },
  { 항목: '자동차세', '1위': 150, '2위': 180, '3위': 200 },
  { 항목: '정비비', '1위': 440, '2위': 450, '3위': 460 },
  { 항목: '감가상각', '1위': 800, '2위': 900, '3위': 950 },
  { 항목: '연료비', '1위': 900, '2위': 960, '3위': 980 }
];
```

### 인사이트 자동 생성:
```tsx
// 어떤 차량이 어떤 항목에서 최저인지
const insights = [
  "✅ 1위는 감가상각이 가장 낮습니다 (800만원)",
  "✅ 1위는 연료비도 경제적입니다 (900만원)",
  "⚠️ 2위는 자동차세가 1위보다 30만원 높습니다"
];
```

## 🎨 시각적 개선 포인트

### Before (Area Chart):
- 색상 영역만 넓음
- 숫자 안 보임
- 차이 불명확

### After (Radar Chart):
- 5개 항목 각 정점
- 겹친 선으로 차이 명확
- 색상 + 투명도로 구분
- 인사이트 텍스트 추가

## ⚡ 구현 우선순위

### Phase 1: Radar Chart (필수)
- 5개 항목 비교
- 3개 차량 겹치기
- 인사이트 텍스트

### Phase 2: 요약 카드 개선 (현재 유지)
- 총 TCO
- 5개 항목 미니 막대
- vs 1위 비교

### Phase 3: Area Chart 제거
- 400px 공간 확보
- 스크롤 감소

---

## 🎯 예상 효과

### 정보 전달력:
- Before: 60% (영역만 넓음)
- After: 95% (항목별 차이 명확)

### 공간 효율:
- Before: 400px (Area) + 300px (카드) = 700px
- After: 300px (Radar) + 300px (카드) = 600px
- **절약: 100px (14%)**

### 사용자 반응:
- Before: "이게 뭐지?"
- After: "오! 1위가 연료비 저렴하네!"

---

## 🚀 구현 시 주의사항

### 1. Radar 정규화
- 5개 항목의 단위가 다름 (취득세 210만원 vs 연료비 900만원)
- **해결**: 각 항목을 비율로 정규화 OR 절대값 그대로 (Auto Scale)

### 2. 색상 일관성
- 1위: 금색 (#F59E0B)
- 2위: 파랑 (#3B82F6)
- 3위: 빨강 (#EF4444)

### 3. 인사이트 자동화
- 각 항목에서 최저값 찾기
- "1위는 X항목에서 Y만원 저렴" 자동 생성

### 4. 툴팁
- Radar 각 정점 hover → "취득세: 210만원"
- 비교: "1위보다 +30만원"
