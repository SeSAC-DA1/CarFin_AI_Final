# ChatbotLanding 서비스 정체성 및 비전

## 🎯 **서비스 정체성**

### **What We Are (우리는 무엇인가)**:
**"학술 논문 기반 차량 추천 시스템"**

- 3개의 검증된 학술 논문을 실제 서비스에 적용한 AI 차량 추천 플랫폼
- 멀티 에이전트 협업으로 복잡한 차량 선택을 단순화하는 서비스
- 15만대 실제 매물 데이터와 객관적 분석 기준을 제공하는 도구

### **What We Are NOT (우리가 아닌 것)**:
- ❌ "세계 최고", "완벽한", "100% 보장" 같은 과장된 주장
- ❌ 모든 문제를 해결하는 만능 솔루션
- ❌ 기존 서비스를 완전히 대체하는 혁신적 플랫폼

---

## 📊 **현실적 가치 제안**

### **Core Value Proposition**:
```
"복잡한 차량 선택을 더 쉽고 정확하게"

✅ 학술적 검증: 3개 논문 기반 신뢰할 수 있는 방법론
✅ 체계적 분석: 3명의 AI가 각자 전문 분야를 담당
✅ 객관적 기준: 6가지 기준으로 정밀 분석
✅ 대용량 처리: 15만대 실데이터 빠른 분석
✅ 개인화: 대화를 통한 맞춤 추천
```

### **Target User**:
- **Primary**: 차량 구매를 고려 중인 일반 소비자
- **Secondary**: 객관적 분석 도구가 필요한 사람
- **Pain Point**: 너무 많은 선택지와 복잡한 비교 과정

---

## 🔍 **차별화 포인트 (현실적 수준)**

### **1. 학술적 신뢰성**:
- SIGIR 2024, RecSys 2019 Best Paper 등 검증된 방법론 적용
- 단순한 키워드 검색이 아닌 체계적 분석 과정
- 투명한 분석 과정 공개

### **2. 멀티 에이전트 접근**:
- 니즈 분석 → 데이터 검색 → 객관적 평가의 전문화된 분업
- 각 AI가 전문 분야에 집중하여 정확도 향상
- 실시간 협업 과정을 사용자가 확인 가능

### **3. 대화형 인터페이스**:
- 복잡한 필터링 없이 자연스러운 대화로 니즈 파악
- 맥락을 기억하고 점진적으로 정밀한 추천 제공
- 불만족 시 즉시 재추천 가능

### **4. 객관적 평가 기준**:
- TOPSIS 다기준 의사결정 방법론 적용
- 6가지 정량적 기준으로 일관된 평가
- 동급 차량과의 객관적 비교 제공

---

## 🎯 **현실적 목표 및 KPI**

### **Service Goals**:
1. **사용자 만족**: 기존 검색 대비 더 정확한 추천 제공
2. **시간 절약**: 복잡한 비교 과정 단순화
3. **신뢰성**: 투명하고 검증 가능한 분석 과정
4. **접근성**: 누구나 쉽게 사용할 수 있는 인터페이스

### **Measurable KPIs**:
- 사용자 만족도: 목표 80%+ (과장 없는 현실적 수준)
- 추천 정확도: 기존 서비스 대비 개선
- 평균 세션 시간: 의미 있는 결과 도출까지의 시간
- 재사용률: 추천 품질에 대한 신뢰 지표

## 💬 **커뮤니케이션 가이드라인**

### **사용할 표현**:
✅ "학술 논문으로 검증된"
✅ "더 정확한 분석"
✅ "객관적 기준"
✅ "체계적 접근"
✅ "투명한 과정"
✅ "도움이 되는"

### **사용하지 않을 표현**:
❌ "세계 최고", "완벽한", "100% 보장"
❌ "혁신적", "획기적", "최첨단"
❌ "모든 문제 해결", "완전 자동화"
❌ "절대적", "무조건", "확실한"

### **톤 앤 매너**:
- **전문적이지만 친근한**: 학술적 근거 + 쉬운 설명
- **신뢰할 수 있는**: 과장 없는 솔직한 소통
- **도움이 되는**: 사용자 문제 해결에 집중
- **투명한**: 과정과 한계를 명확히 설명

---

## 🚀 **장기 비전**

### **Phase 1 (현재)**:
차량 추천 도메인에서 학술 논문 기반 AI 시스템의 실용성 검증

### **Phase 2 (6개월)**:
사용자 피드백 기반 알고리즘 개선 및 추천 정확도 향상

### **Phase 3 (1년)**:
다른 복잡한 의사결정 도메인으로 확장 (부동산, 교육 등)

### **Long-term Vision**:
**"복잡한 선택을 단순하게 만드는 AI 도구"**
- 학술적 신뢰성을 바탕으로 한 의사결정 지원 플랫폼
- 투명하고 설명 가능한 AI 시스템의 표준 제시
- 일반인도 쉽게 활용할 수 있는 고도화된 분석 도구

---

## 📋 **서비스 원칙**

### **1. 신뢰성 우선**:
- 과장보다는 정확성
- 검증된 방법론만 적용
- 한계와 불확실성 솔직히 공개

### **2. 사용자 중심**:
- 기술 자랑보다는 사용자 문제 해결
- 복잡한 과정을 단순한 인터페이스로
- 사용자가 이해할 수 있는 설명 제공

### **3. 투명성**:
- 모든 분석 과정 공개
- AI 판단 근거 명확히 제시
- 데이터 출처와 방법론 공개

### **4. 지속적 개선**:
- 사용자 피드백 적극 반영
- 새로운 학술 연구 지속 모니터링
- 기술적 한계 인정하고 개선 노력

이러한 명확한 정체성과 현실적 비전을 바탕으로, 과장 없이도 충분히 차별화된 가치를 제공할 수 있는 서비스로 포지셔닝합니다.
