## 🚨 발견된 주요 문제점

### ❌ **1. 톤앤매너 불일치 (Critical)**

#### **문제점**
현재 프로젝트 전반에 **존댓말**과 **반말**이 혼용되어 있으며, 지나치게 **캐주얼한 표현**이 사용되고 있습니다.

| 위치 | 현재 텍스트 | 문제점 |
|------|------------|--------|
| **Hero.tsx** | "어떤 차 살지 고민? AI가 알아서 찾아드려요" | 반말 + 존댓말 혼용 |
| **Hero.tsx** | "딱 3분이면 끝", "복잡한 고민은 이제 그만" | 마케팅 카피 느낌 |
| **Hero.tsx** | "어떻게 하는지 볼래요" (버튼) | 반말 (너무 캐주얼) |
| **ProfileSetup.tsx** | "어떻게 불러드릴까요?" | 존댓말 |
| **ProfileSetup.tsx** | "더 정확한 추천을 위해 기본적인 정보가 필요해요" | 반말 |
| **ChatWebSocketHandler** | "어떤 차 찾으세요? 그냥 평소에 말하듯이 편하게 얘기해주세요" | 반말 |
| **Onboarding.tsx** | "3분만에 완벽한 체험" | 마케팅 용어 |

#### **포지셔닝 문제**
- **핀테크 공모전 심사위원**: 전문성 부족하게 보일 수 있음
- **기업 인사담당자**: B2C 서비스로 오해할 수 있음
- **학술적 신뢰성**: 논문 기반 시스템인데 텍스트가 너무 캐주얼

#### **권장 수정**
✅ **존댓말로 통일** (프로페셔널하면서도 친근함 유지)
✅ **마케팅 카피 제거** → 객관적 사실 표현

### ❌ **2. 데이터 정확성 불일치 (Critical)**

#### **문제점**
**"15만대"**와 **"127,378대"**가 혼용되고 있습니다.

| 위치 | 현재 텍스트 | 문제점 |
|------|------------|--------|
| **Hero.tsx:32** | "15만대 중에서 딱 3대만" | 부정확한 반올림 |
| **ChatWebSocketHandler:46** | "15만대 중에서 딱 맞는 차량" | 부정확한 반올림 |
| **Onboarding.tsx** (Phase 1 수정 완료) | "127,378대 실시간 중고차 데이터" | ✅ 정확한 수치 |

#### **포지셔닝 문제**
- **학술적 신뢰성**: Phase 1에서 fake 통계를 제거했는데, 여전히 부정확한 수치 사용
- **데이터 일관성**: 같은 프로젝트 내에서 15만대 vs 127,378대 혼용

#### **권장 수정**
✅ **"127,378대"로 통일** (정확한 실제 데이터 강조)
