# 🎯 CARFIN AI - 프로젝트 최종 요약

## 📋 프로젝트 개요

**CARFIN AI**는 학술 논문 3개를 기반으로 구현된 차량 추천 시스템으로, 127,378개 실제 매물 데이터에서 사용자 맞춤 차량 3대를 3분 내에 추천합니다.

### 🎓 적용된 학술 논문
1. **MACRec (SIGIR 2024)** - Multi-Agent Collaborative Recommendation
2. **Alibaba Re-ranking (RecSys 2019)** - 개인화 재정렬 알고리즘
3. **AHP-TOPSIS** - 다기준 의사결정 분석

---

## 🏆 핀테크 공모전 핵심 차별점

### 1. TCO(총 소유비용) 계산 시스템 ⭐ 핵심!

**기존 플랫폼 vs CARFIN AI**
```
기존 (카카오모빌리티, KB차차차):
차량 가격만 표시 → 2,500만원

CARFIN AI:
차량 가격 + 3년 총 소유비용 → 2,500만원 + TCO 1,850만원
= 실제 부담 4,350만원

💡 차이: 가격만 보면 저렴해 보이지만, TCO를 보면 더 비쌀 수 있음!
```

**5가지 비용 항목 (법적 근거 기반)**
1. **취득세**: 차량가 × 7% (지방세법 제11조)
2. **자동차세**: 배기량별 세율 + 차령감액 (지방세법 제127조)
3. **정비비**: 88원/km × 연간주행거리 (DOE/ANL 표준)
4. **감가상각**: 정률법 20% (한국회계기준)
5. **연료비**: (연간주행 / 연비) × 실시간 유가

**개인화 변수**
- 연간 주행거리 (기본 15,000km, 사용자 설정 가능)
- 보유 기간 (3년/5년/7년)
- 연료비 실시간 반영

### 2. 학술 논문 기반 신뢰성

**구현 정확도**
